# Flux

The Flux control plane: the bootstrap, the Kustomizations that point at the rest of
`030-software/fluxcd`, and the SOPS key Flux uses to decrypt secrets.

There is no `kustomization.yaml` in this directory. `flux-system/gotk-sync.yaml` sets
`spec.path` to this directory, and Flux generates the kustomization for it.

All of them run with `wait: true` and `prune: true`, so deleting an object here
deletes it from the cluster.

## flux-system

| File | Contents |
|---|---|
| [`gotk-components.yaml`](flux-system/gotk-components.yaml) | The Flux CRDs and controllers. **Generated - do not edit.** |
| [`gotk-sync.yaml`](flux-system/gotk-sync.yaml) | The `GitRepository` for this repo and the root Kustomization. Generated by `flux bootstrap`. |
| [`kustomization.yaml`](flux-system/kustomization.yaml) | Assembles the three above and patches the controllers. |
| [`secret.yaml`](flux-system/secret.yaml) | SOPS-encrypted webhook token. Commented out of `resources`. |
| [`webhook.yaml`](flux-system/webhook.yaml) | HTTPRoute for the notification receiver. |

`kustomization.yaml` patches the installed controllers rather than forking them:

- `kustomize-controller` runs with `--concurrent=20` and a memory-backed temp volume.
- `source-controller` with a bounded Helm cache (`--helm-cache-max-size=10`,
  `--helm-cache-ttl=60m`, `--helm-cache-purge-interval=5m`).
- `helm-controller` with `--feature-gates=OOMWatch=true` and a 95% memory threshold,
  so a leaking release shuts down gracefully instead of being OOM-killed.
- Every Flux Deployment gets `cluster-autoscaler.kubernetes.io/safe-to-evict: "true"`,
  a soft preference for the `metal` region and a toleration for the
  `node.kubernetes.io/nuc` taint, so Flux can move when nodes come and go.
- The `GitRepository` and the root Kustomization are patched to a 24h interval, and
  the `GitRepository` ignores `.git/`, `.github/` and `.sops.yaml` so docs and
  workflow changes do not trigger a reconcile.

`gotk-components.yaml` is refreshed nightly by
[`../../.github/workflows/update-flux.yml`](../../.github/workflows/update-flux.yml),
which opens the PR for you. Never hand-edit it.

## Secrets

[`.sops.yaml`](.sops.yaml) and [`.sops.pub.asc`](.sops.pub.asc) configure SOPS with
PGP, encrypting only the `data` and `stringData` keys. The private key reaches the
cluster as the `sops-gpg` secret named by every Kustomization's
`spec.decryption.secretRef`.
